How this runs

  1. Scan searches public Bing and DuckDuckGo results. It cannot open BizBuySell’s or LoopNet’s directories (those sites block the server). Most owner-financed ads are financing-only and would not qualify anyway.
  2. A listing is kept only when it offers seller financing and includes real estate — a building or operating business, not vacant land or a development site. LoopNet /Listing/ pages count as real estate when they are an improved property with seller/owner financing.
  3. Search engines only index a thin slice of listing pages, so Scan often returns the same handful. Listings already in your list are skipped. A GitHub Action can search from a different IP and import matches.
  4. Schedule npm run scan on your VPS, or use the GitHub Action once this app is deployed.
  5. Add notes on a listing and mark it Called after you talk to the seller.
