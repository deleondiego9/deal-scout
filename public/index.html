How this runs

  1. This app searches public listing results for seller financing and real estate included.
  2. Each listing URL is stored once. Later scans skip it instead of duplicating the card.
  3. A Cursor agent can also post deals it finds. Same dedupe rules apply.
  4. Schedule npm run scan on your VPS, or use the GitHub Action once this app is deployed.
  5. On your phone: open the public HTTPS URL, then Add to Home Screen. That is the phone app.
